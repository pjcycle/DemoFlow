# Security Policy

| Version | Supported |
| ------- | ------------------ |
| 1.x | :white_check_mark: |

## Reporting a Vulnerability

DemoFlow is a Mac App Store application. If you discover a security vulnerability, **do not open a public GitHub Issue**.

Please report vulnerabilities privately:

1. **Email**: Send details to the maintainer directly via GitHub
2. **GitHub Security Advisories**: Use the "Report a vulnerability" option under the repository's Security tab

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

## Response Timeline

- Acknowledgment: within 48 hours
- Initial assessment: within 7 days
- Fix timeline: varies by severity

## Public Disclosure

We follow responsible disclosure practices and will coordinate public disclosure with reporters.
